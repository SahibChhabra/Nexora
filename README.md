# Nexora

A modern and responsive digital agency website built with **React.js** and **Tailwind CSS**.

## ✨ Features

- Fully responsive design
- Modern and clean UI
- Reusable React components
- Services and projects sections
- Team section
- Contact form
- Newsletter section

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite
